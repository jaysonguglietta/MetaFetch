# MetaFetch 2.02

MetaFetch 2.02 is a reliability and workflow update for movie and TV tagging.

## Highlights

- Correctly reports an empty GitHub release channel instead of showing HTTP 404 as a connectivity failure.
- Adds CSV and JSON dry-run exports for full-season TV reconciliation.
- Makes each reconciliation row explain whether metadata will be applied or why no change is planned.
- Improves verified MP4 replacement on external volumes.
- Expands automated coverage for update checks, season plans, and transactional saves.

## Update Safety

The downloadable DMG and its matching SHA-256 sidecar are produced by the guarded release workflow. Production publication requires Developer ID signing, Apple notarization, stapling, Gatekeeper assessment, and checksum verification.
